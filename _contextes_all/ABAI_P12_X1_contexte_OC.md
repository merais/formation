# Option B - Mission fictive : Créez et automatisez une architecture de données

## Comment allez-vous procéder ?

Cette mission suit un scénario de projet professionnel.

Avant de démarrer, nous vous conseillons de :
- lire toute la mission et ses documents liés ;
- prendre des notes sur ce que vous avez compris ;
- consulter les étapes pour vous guider ;
- préparer une liste de questions pour votre première session de mentorat.

## Prêt à mener la mission ?

Vous êtes Data Engineer freelance. Vous avez été contacté par **Sport Data Solution**, une start-up co-fondée par **Alexandre** (amateur de vélo) et **Juliette** (marathonienne). Leur entreprise développe des outils pour valoriser les données sportives des salariés, dans le cadre de leur engagement bien-être au travail.

## Vous recevez un mail de Juliette :

```
De : Juliette
À : Moi
Objet : POC pipeline de données sportives

Bonjour,

Comme discuté, nous souhaitons mettre en place un POC d'un pipeline de données de bout en bout.

Contexte :
Nous proposons à nos clients un programme de mobilité douce avec deux avantages salariés :
- Prime de 5% sur le salaire si l'employé vient au travail à vélo, trottinette ou à pied
- 5 jours de bien-être offerts par an

Objectifs du POC :
- Créer un pipeline complet : extraction, transformation, chargement, tests et monitoring
- Déclencher une notification Slack pour chaque activité physique enregistrée
- Démontrer la faisabilité, les données collectées et l'impact financier potentiel

Restitution attendue :
- Support de présentation
- Démo live du pipeline
- Rapport PowerBI avec historique rejouable

Pièces jointes : données RH, données sportives, note de cadrage

Bonne journée,
Juliette

P.J. : données_RH.xlsx, données_sportives.csv, note_de_cadrage.pdf
```

Cette mission ne propose pas d'étapes guidées sur la page OC. Les étapes sont libres au choix du candidat.

---

## Objectifs du POC

1. Mettre en place un pipeline de données automatisé de bout en bout.
2. Intégrer les données RH et sportives dans une infrastructure cohérente.
3. Calculer les avantages salariés (prime mobilité douce, jours bien-être).
4. Déclencher des notifications Slack à chaque activité enregistrée.
5. Produire un rapport PowerBI illustrant l'impact financier et l'historique des activités.
